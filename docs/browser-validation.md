# 浏览器共享验证记录

验证日期：2026-09-09。Windows 11、.NET 8、已授权 Pianoteq 9.0.1，Windows Audio 48 kHz / 480 帧输出。本机 Edge/Chromium 正常自动播放策略，用户点击进入琴房；未使用自动播放绕过参数。

| 验证项 | 结果 |
| --- | --- |
| Release 构建 | 0 警告、0 错误 |
| Pianoteq 进程采集 | 约 2 秒收到 199 个 10 ms 音频帧；PCM16 峰值 8995 |
| 其他进程声音隔离 | 独立进程播放 1 kHz 音频，系统回放峰值 11999；Pianoteq 专用采集峰值仅 1（量化噪声） |
| WebRTC 实际解码 | 收到 140 个 RTP 音频包，音频能量 0.02646，测试期间丢包 0；播放元素处于播放且未静音 |
| WebSocket 备用音频 | 禁用浏览器 WebRTC 后，AudioWorklet 输出峰值 0.18539，证明备用声音进入播放图 |
| 手机触控 | 390 × 844 视口、真实浏览器触摸事件；三指和弦、全部松开与无横向溢出通过 |
| 鼠标滑奏 | 琴键外松音、滑回重新发音通过 |
| 多用户同音 | 两人持有同一个音，释放一人后另一人的音符仍保留 |
| 失联 | 约 1.2 秒无按键状态更新自动释放，直接关闭浏览器也释放 |
| 访问限制 | 错误邀请密钥被拒绝；不存在的本机文件路径返回 404；无 JavaScript/CSP 错误 |
| 桌面集成 | 真实 WPF 共享窗口能开启采集与网页服务 |
| 录制兼容 | 共享开启时 F9 锁定远程琴键，Esc 取消恢复；完整录制保存 48 kHz / 24-bit WAV 和尾音，随后恢复输入 |
| 关闭窗口 | 录制中关闭会取消并保留之前已完成的录音 |
| 既有基础测试 | MIDI 解析、默认映射、音名、Format 1 速度合并、running status、异常 MIDI 拒绝均通过 |

测试源代码与运行步骤见 [tests/BrowserSmoke](../tests/BrowserSmoke/)。桌面录音兼容测试使用独立测试目录，未改动用户的 MIDI 或录音。

这些结果来自本机测试，不代表公网端到端延迟。真实手机硬件、外网穿透和 TURN 连通性尚待用户配置之后验证。
